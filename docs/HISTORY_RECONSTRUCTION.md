# How this repository history was produced

The original repository was lost. This history was **reconstructed** from the Jira export of project SCRUM (status changes, assignees, sprints) together with the final project files. Commit dates follow the Jira status timeline of each task and each commit is attributed to the task assignee, who agreed to this reconstruction. It is not the original commit history.

Script: `build_repo_from_jira.py` (kept alongside the Jira export).
